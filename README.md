# CentiMeet 📍

**Βρες το δίκαιο σημείο συνάντησης για όλη την παρέα.**
Καφές, φαγητό, ποτό, σινεμά — κάθε φίλος δηλώνει από πού ξεκινά και με τι μέσο,
και το CentiMeet προτείνει μαγαζιά όπου **κανείς δεν ταλαιπωρείται περισσότερο από τους άλλους**.

---

## Δομή

```
centimeet/
├── apps/
│   ├── api/        Backend (Node + Fastify): αλγόριθμος, Google Places/Routes, parking, κόστος
│   └── mobile/     Εφαρμογή iOS/Android/tablet (React Native + Expo Router)
├── packages/
│   └── shared/     Κοινός κώδικας: τύποι, validation, αλγόριθμος δικαιοσύνης, κόστος, μηνύματα κοινοποίησης
└── supabase/
    └── migrations/ Σχήμα βάσης: λογαριασμοί, φίλοι, έξοδοι, μηνύματα + Row Level Security
```

## Πώς δουλεύει ο αλγόριθμος

1. **Υποψήφια σημεία:** σταθμισμένο κέντρο της παρέας (όποιος πάει με τα πόδια «τραβάει» το κέντρο), πλέγμα 3×3 γύρω του και κόμβοι της πόλης (Σύνταγμα, Καλαμαριά…). Με εκτίμηση χρόνου κρατάμε τα **8** πιο υποσχόμενα (`apps/api/src/engine/areas.ts`).
2. **Πραγματικοί χρόνοι** από κάθε άτομο προς κάθε σημείο με το δικό του μέσο (Google Routes, μία κλήση ανά ομάδα μέσου):
   - με **ώρα συνάντησης**: οχήματα με κίνηση εκείνης της ώρας (αναχώρηση = συνάντηση − διάρκεια, απαισιόδοξη εκτίμηση), συγκοινωνίες με ώρα άφιξης
   - χωρίς ώρα: «τώρα», χωρίς κίνηση (φθηνότερο)
   - + χρόνος εύρεσης parking ανά περιοχή, μηχανή ≈ 15% γρηγορότερη από αυτοκίνητο
3. **Δίκαιο σημείο** (`packages/shared/src/fairness.ts`):
   `κόστος = 1.0·μέγιστος χρόνος + 0.8·(μέγιστος − ελάχιστος) + 0.5·μέσος όρος + 2.5·μέσο κόστος(€)`
   → κύριο σημείο + 2 εναλλακτικά σε άλλες περιοχές (≥ 1.2 km).
4. **Μαγαζιά** σε **300 m** (→ 500 → 800 αν δεν βρεθούν 6), σε λειτουργία και **ανοιχτά την ώρα της συνάντησης** (τουλάχιστον 1 ώρα).
5. **Σειρά:** σταθμισμένη βαθμολογία (Bayesian — λίγες κριτικές «τραβιούνται» προς τον μέσο όρο 4.2), μείον ποινή «ίσως γεμάτο».
6. **«Ίσως έχει κόσμο» 📞** (`packages/shared/src/crowd.ts`): το Google **δεν** δίνει popular times μέσω API, οπότε είναι *εκτίμηση* από δημοφιλία, ώρα αιχμής ανά είδος, μέγεθος παρέας και `goodForGroups`. Για 6+ άτομα σε πιθανό γεμάτο μαγαζί εμφανίζεται 📞 με πρόταση να καλέσουν για τραπέζι.
7. Όταν η παρέα διαλέξει μαγαζί: **πλάνο ανά άτομο** — χρόνος, γραμμές συγκοινωνιών, parking + χρόνος εύρεσης, κόστος με **διόδια**, link πλοήγησης.

## Κόστος

- **`COST_MODE=lean` (προεπιλογή, Φάση 1):** 5 σημεία, ακτίνες 300 → 600 m, εναλλακτικές περιοχές με μαγαζιά «κατά παραγγελία», Photon για διευθύνσεις. Χωράει ~600 αναζητήσεις/μήνα στα **δωρεάν** όρια του Google.
- **`COST_MODE=growth` (Φάση 2):** 8 σημεία, δεύτερος υπολογισμός κίνησης, μαγαζιά για όλες τις περιοχές. ~$0,40–0,55 ανά αναζήτηση 4 ατόμων.
- **Φρένο κόστους:** μετρητές ανά υπηρεσία Google στη βάση (`api_usage`)· στο 90% του δωρεάν ορίου → δωρεάν εφεδρική λειτουργία (εκτιμώμενοι χρόνοι, μαγαζιά OpenStreetMap). Όριο 10 αναζητήσεων/χρήστη/ημέρα.
- Στήσιμο παραγωγής με ~€0/μήνα (Supabase, Cloud Run, Brevo/Resend): **[docs/DEPLOY.md](docs/DEPLOY.md)**.

## Γρήγορη εκκίνηση

Χρειάζεσαι **Node.js 22+**.

```bash
npm install

# 1) Backend με ψεύτικα δεδομένα (χωρίς κλειδιά, χωρίς κόστος)
cp apps/api/.env.example apps/api/.env
npm run dev:api            # → http://localhost:8787/health

# 2) Εφαρμογή
cp apps/mobile/.env.example apps/mobile/.env
#    βάλε στο EXPO_PUBLIC_API_URL την IP του υπολογιστή σου (π.χ. http://192.168.1.10:8787)
npm run dev:mobile         # σκάναρε το QR με το Expo Go
```

Χωρίς ρυθμίσεις Supabase πάτα «Συνέχεια χωρίς λογαριασμό» για να δοκιμάσεις την εύρεση σημείου.

### Tests

```bash
npm test          # αλγόριθμος, κόστος, κοινοποίηση, έξοδοι, API, Google matrix chunking
npm run typecheck # shared + api + mobile
npm run test:db   # migrations + RLS/RPC σε προσωρινό container PostGIS (χρειάζεται μόνο Docker)
```

## Ρύθμιση υπηρεσιών

### Supabase (λογαριασμοί, φίλοι, μηνύματα)
1. Δημιούργησε project στο [supabase.com](https://supabase.com) (περιοχή: EU — Frankfurt για GDPR).
2. Τρέξε **με τη σειρά** όλα τα αρχεία του `supabase/migrations/` (SQL editor ή `supabase db push`).
3. Authentication → Providers → Email: ενεργοποίησε το **Email OTP** και άλλαξε το template ώστε να στέλνει τον κωδικό `{{ .Token }}`.
4. Αντέγραψε URL + anon/publishable key στο `apps/mobile/.env` και το URL στο `apps/api/.env`.

### Αναζήτηση διεύθυνσης (αφετηρίες)
Χωρίς κλειδί Google, η αναζήτηση διεύθυνσης και το pin στον χάρτη χρησιμοποιούν **Photon (OpenStreetMap)** — δωρεάν, πραγματικές διευθύνσεις.
Το δημόσιο Photon είναι για ανάπτυξη· στην παραγωγή χρησιμοποιείται η Google (ή δικός σας Photon server με `PHOTON_URL`).

### Google Maps Platform (πραγματικά δεδομένα)
1. Ενεργοποίησε **Places API (New)** και **Routes API**.
2. Βάλε το κλειδί στο `apps/api/.env`, `USE_MOCK_PROVIDERS=false` και `SUPABASE_SERVICE_ROLE_KEY` (μετρητές κόστους).
3. Περιόρισε το κλειδί σε αυτά τα δύο APIs και βάλε **budget alert** στο billing. Αναλυτικά: [docs/DEPLOY.md](docs/DEPLOY.md).

## Εμφάνιση

Όλη η εμφάνιση είναι στο **`apps/mobile/src/theme.ts`**: χρώματα (φωτεινά/σκοτεινά), γραμματοσειρά, μεγέθη, στρογγυλέματα.
Εικονίδιο & splash: `npm run icons` (ή `python apps/mobile/scripts/make-icons.py "#χρώμα"`), ή βάλε δικά σου PNG στο `apps/mobile/assets/`.
Κείμενα: `apps/mobile/src/i18n/index.ts`.

## Σημειώσεις

- **Τιμές** εισιτηρίων, ταξί και καυσίμων στο `packages/shared/src/cities.ts` είναι **ενδεικτικές** — επαλήθευσέ τες πριν το launch.
- Νέα πόλη = νέα εγγραφή στο `CITY_CONFIG` (κέντρο, κόμβοι, εισιτήριο, ταξί).
- Το κλειδί Google **δεν μπαίνει ποτέ** στην εφαρμογή — όλες οι κλήσεις περνούν από το backend.
- **Αφετηρίες σε αποθηκευμένες εξόδους** (`outing_origins`) τις βλέπει μόνο ο ίδιος και ο διοργανωτής· ο πίνακας δεν έχει πολιτικές RLS και δεν είναι στο Realtime — πρόσβαση μόνο μέσω των RPC `create_outing`, `declare_origin`, `set_rsvp`, `get_outing_participants`, `my_outings`, `invite_to_outing`.
